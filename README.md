# Gothic LockPicker — автоматизация взлома замков

Утилита на C# (.NET 7, WinForms) для автоматической отправки комбинаций клавиш
взлома замков в игру. Находит окно игры по заголовку и эмулирует нажатия
**W / A / S / D** со скан-кодами (надёжно для игр).

## Возможности

- Поиск окна игры по части заголовка (по умолчанию `Gothic 1 Remake`).
- Ввод последовательности взлома в свободном формате (см. ниже).
- Управление:
  - **W** — следующая пластина
  - **S** — предыдущая пластина
  - **A** — поворот влево ◀
  - **D** — поворот вправо ▶
- Автоматическая навигация между пластинами (рассчитывает, сколько раз нажать W/S).
- Настраиваемая задержка между нажатиями (по умолчанию **1000 мс**).
- Обратный отсчёт перед стартом — успеть переключиться в игру.
- Сохранение настроек, последней последовательности, позиции и размера окна
  между запусками (`settings.json` в папке с исполняемым файлом).

## Формат последовательности

Каждый шаг — отдельная строка. Распознаётся номер пластины (римский `I..X`
или арабский) и направление (слова `Влево`/`Вправо` либо стрелки `◀ ▶ ← →`):

```
Шаг 1: Пластина I ➔ Вправо ▶
Шаг 2: Пластина II ➔ Вправо ▶
Шаг 3: Пластина III ➔ Влево ◀
Шаг 4: Пластина I ➔ Вправо ▶
Шаг 5: Пластина III ➔ Влево ◀
Шаг 6: Пластина I ➔ Вправо ▶
Шаг 7: Пластина III ➔ Влево ◀
Шаг 8: Пластина IV ➔ Влево ◀
Шаг 9: Пластина V ➔ Влево ◀
```

## Сборка и запуск

Требуется .NET 8 SDK.

```
cd LockPicker
dotnet build
dotnet run
```

## Использование

1. Запустите игру.
2. Запустите Gothic LockPicker.
3. Укажите заголовок окна игры и нажмите **«Найти окно»**.
4. Вставьте последовательность взлома.
5. Задайте задержку и (если нужно) стартовую пластину — ту, на которой
   сейчас стоит фокус в игре.
6. Нажмите **▶ Старт**, переключитесь в окно игры в течение обратного отсчёта.

> ⚠️ Запускайте Gothic LockPicker **от имени администратора**, если игра запущена
> с повышенными правами — иначе Windows заблокирует отправку клавиш (UIPI).

## Примечание о стартовой пластине

Движок отслеживает текущую пластину относительно стартовой позиции. По умолчанию
считается, что фокус на пластине **I** (1). Если в игре фокус на другой пластине,
укажите её в поле «Текущая (стартовая) пластина».
